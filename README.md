# Learning C in 4 Days

A hands-on, beginner-friendly repo where I learn the C programming language in 4 days.
Each day has its own set of programs with comments, so the code doubles as notes.

## What's Inside

| Day | Topic | What I practiced |
|-----|-------|------------------|
| 1 | Basics | Syntax, variables, data types, input/output, operators |
| 2 | Control flow | if/else, switch, for / while / do-while loops |
| 3 | Functions and arrays | Functions, recursion, arrays, strings |
| 4 | Pointers and structures | Pointers, `struct`, dynamic memory (`malloc`/`free`) |

> Edit the table above to match the folders in this repo.

## How to Run

You need a C compiler such as GCC.

```bash
# clone the repo
git clone https://github.com/shravanpvt13-bit/learning_c_for-4-days.git
cd learning_c_for-4-days

# compile and run any program
gcc day1/hello.c -o hello
./hello
```

On Windows, use MinGW or WSL, then run `hello.exe`.

## Goals

- Build a strong foundation in C before moving to data structures and algorithms
- Understand how memory, pointers and structures work
- Write small programs every day instead of only reading theory
